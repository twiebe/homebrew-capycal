# Homebrew tap for Capycal

[Capycal](https://github.com/twiebe/capycal) syncs calendars one way and copies only what you allow.

```bash
brew install twiebe/capycal/capycal              # CLI (macOS on Apple silicon, Linux)
brew install --cask twiebe/capycal/capycal-app   # menu bar app (macOS)
```

`brew services start capycal` runs the CLI in the background with your default config. The cask installs `Capycal.app` without linking its bundled CLI, so both can be installed side by side. The app is not notarized: before its first start, run `xattr -dr com.apple.quarantine /Applications/Capycal.app`.

`Formula/capycal.rb` and `Casks/capycal-app.rb` are generated by the release workflow of Capycal from `packaging/homebrew/`. Change them there, not here.

See the [documentation](https://capycal.app/docs/installation.html#homebrew) for details.
